## 关于 QiStore

QiStore 是面向群晖（Synology）NAS 用户的开源套件生态，重点解决老款群晖设备、旧版 DSM 及不同硬件平台的软件兼容问题。我们关注原生套件（SPK）的打包与适配，具体支持范围以各项目公布的设备、DSM 版本和硬件架构为准。

## 组织规范

1. **第三方软件保留官方名称。** 第三方个人或公司开发的软件严格使用原项目的官方名称，不得擅自添加 `Qi` 前缀。
2. **自主开发的软件可以使用 `Qi` 前缀。** 该前缀用于标识 QiStore 自主开发的项目。
3. **所有项目以简体中文为主，英文为辅。** 项目说明、使用文档和发布信息优先提供简体中文，英文用于补充。

## 开源、版权与商标

QiStore 尊重原作者、开源许可证、版权及商标。适配和分发第三方软件时，遵守上游许可证，保留适用的署名、版权与许可声明，并清楚标注上游来源。QiStore 独立维护其第三方适配套件，不冒充 Synology 或任何上游项目的官方发行方。

## 发展规划

| 方向 | 状态 | 计划 |
| --- | --- | --- |
| 多平台 SPK 自动构建 | 规划中 | 按目标 DSM 版本和硬件架构构建群晖原生套件。 |
| GitHub Releases 自动发布 | 规划中 | 将通过构建和检查的 SPK 自动发布到对应项目的 GitHub Releases。 |
| 套件源自动同步 | 规划中 | 将已发布套件的版本、下载地址与兼容信息同步到套件源。 |
| 群晖套件更新机制 | 规划中 | 让 DSM 套件中心通过套件源获取适配当前设备的更新信息。 |

## English summary

QiStore is an open-source package ecosystem for Synology NAS users, focused on software compatibility across older devices, legacy DSM versions, and different hardware platforms.
